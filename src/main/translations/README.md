# Translations

Add translations in `<locale>.json` files in this directory, then run `./gradlew runData`.
For example, `zh_cn.json` may define `item.farmlifecrops.cabbage`,
`item.farmlifecrops.cabbage_seeds`, and `block.farmlifecrops.cabbage`.

English content names are declared in Java. Do not duplicate those keys in
`en_us.json` or edit generated language files directly.
